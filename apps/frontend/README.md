# Go2Abroad frontend

The public website is a React single-page application built with Vite.

## Development

From the repository root:

```bash
npm run dev:frontend
```

Or from this directory:

```bash
npm install
npm run dev
```

The development server runs at <http://localhost:5173>.

To start the complete monorepo from this directory, run:

```bash
npm run dev:all
```

## Production

```bash
npm run build
npm run preview
```

The application is served from the root URL (`/`). Client-side routes are
handled by React Router.
